# Simon's Fitness & Progress Web-App

Diese Web-App dient als personalisiertes Coaching-Dashboard für Simon (Startgewicht 104 kg, Bauchumfang 110 cm), begleitet von Coach Matthias. Sie fokussiert sich auf Gewichtsabnahme, Rückenschutz (Hebe-Mechaniken) und Atemstütze für klassischen Gesang.

## Funktionen
- **100% Offline-fähig (PWA)**: Die App läuft komplett im Browser und kann als App auf dem Smartphone-Homescreen installiert werden.
- **Lokale Datenhaltung**: Keine Serverkosten, alle Daten liegen sicher im `localStorage`.
- **Interaktives Workout**: Ein 15-Minuten Bodyweight-Zirkel mit eingebautem 30-Sekunden Pausentimer (Web Audio).
- **Fortschritt-Charts**: Grafische Auswertung von Gewicht und Bauchumfang via Chart.js.
- **1-Klick-Sharing**: Automatisierte Erstellung eines kurzen Check-in-Berichts für Coach Matthias (z. B. via WhatsApp).

## Nutzung
1. **Lokal starten**: Einfach `index.html` in einem modernen Browser öffnen oder per lokaler Live-Server Extension starten.
2. **Auf dem Smartphone**: Die Seite aufrufen, im Menü (iOS Safari / Android Chrome) auf "Zum Home-Bildschirm" klicken.

## GitHub Pages Deployment
1. Gehe in deinem Repository auf GitHub.
2. Klicke auf **Settings** -> **Pages**.
3. Wähle unter *Build and deployment* die Source `Deploy from a branch`.
4. Wähle den Branch `main` und klicke auf *Save*.
5. Nach 1-2 Minuten ist die App live!
